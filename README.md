# Mini Music Streaming & Playlist Manager

A beginner-friendly but professional full-stack Music Streaming & Playlist Manager built with Java, Spring Boot, MySQL, and vanilla web technologies (HTML/CSS/JS).

## About
This project is designed for freshers looking for a clean, end-to-end full-stack application to learn from and showcase in interviews. It deliberately avoids overly complex architectures (no microservices, no complex JWT auth, no React/Angular overhead) while still maintaining a professional look and implementing core features expected of a music platform.

## Features
- **User Authentication**: Simple login and registration (BCrypt hashed passwords).
- **Music Playback**: Persistent bottom music player with HTML5 `<audio>`, play/pause, volume control, and progress bar.
- **Song Catalog**: Browse all songs, search by title/artist.
- **Playlists**: Create/delete playlists, and add/remove songs.
- **Favorites**: Mark/unmark songs as favorites and view them.
- **Admin Dashboard**: A simple panel for `ADMIN` users to add or delete songs dynamically.
- **Responsive UI**: Modern dark theme with CSS variables, hover effects, and a premium aesthetic using pure CSS.

## Technologies
- **Backend**: Java 17, Spring Boot, Spring Web (REST API), Spring Data JPA
- **Database**: MySQL 
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Build Tool**: Maven

## Architecture
```text
Frontend (HTML/JS) 
   → (REST API calls over HTTP) 
Spring Boot REST Controllers 
   → Spring Services (Business Logic) 
   → Spring Data JPA (Repositories) 
   → MySQL Database
```

## How to Run

### 1. Prerequisites
- Install Java 17
- Install MySQL Server
- Have an IDE (like IntelliJ IDEA or VS Code) installed

### 2. Database Setup
1. Open MySQL Workbench or your MySQL command line.
2. Create the database: `CREATE DATABASE music_app;`
3. The tables will be auto-generated by Hibernate when you run the backend.
4. After running the app once, you can run the SQL script found at `database/database.sql` to populate sample users, songs, and playlists.

### 3. Backend Setup
1. Open `backend/src/main/resources/application.properties`.
2. Update `spring.datasource.username` and `spring.datasource.password` with your MySQL credentials.
3. Open the `backend` folder in your IDE.
4. Run the main class: `com.musicapp.MusicAppApplication`.
5. The backend will start on `http://localhost:8080`.

### 4. Frontend Setup
1. The frontend doesn't require Node.js or any build step.
2. Simply open `frontend/index.html` in your web browser. Or for best results, use a simple live server (like the VS Code Live Server extension) to serve the folder.

### Default Users (From sample data)
- **Admin**: `admin@musicapp.com` / `password`
- **User**: `user@musicapp.com` / `password`

## Important Java Classes Explained
- `User.java`, `Song.java` (Entities): These represent the tables in our MySQL database. We use JPA annotations (`@Entity`, `@Table`) to map Java objects to relational data.
- `UserRepository.java` (Repositories): Interfaces that extend `JpaRepository`. They give us free database operations (save, findById, delete) without writing SQL.
- `SongService.java` (Services): Where the business logic lives. Controllers call Services, and Services call Repositories.
- `SongController.java` (Controllers): Exposes the REST APIs. Uses `@RestController` and `@GetMapping`/`@PostMapping` to map URLs to Java methods.

## Common Errors
- `Access Denied for user 'root'@'localhost'`: Check your MySQL password in `application.properties`.
- `Failed to load resource (CORS)`: Make sure your Spring Boot app has `@CrossOrigin(origins = "*")` on controllers (which is included by default in this project).
- `Port 8080 already in use`: Another application is running on port 8080. Stop it or change `server.port=8081` in `application.properties`.
